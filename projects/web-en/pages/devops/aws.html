2. Compute & Serverless

EC2 — Máy ảo truyền thống

Chọn AMI (hệ điều hành) + instance type (CPU/RAM) + key pair (SSH). Trả theo giây — phù hợp workload cần kiểm soát đầy đủ, chạy app lâu dài. (Pick an AMI, instance type, and key pair. Pay per second — full control, good for long-running apps.)

ECS & EKS — Container

ECS

Managed container service riêng của AWS — đơn giản, dùng Fargate (không quản lý server) hoặc EC2. Task definitions + services.

EKS

Managed Kubernetes — chuẩn K8s nhưng AWS lo control plane. Hợp khi đã chuẩn hóa với K8s.

# ECS Task Definition (container đơn giản)
{
  "family": "myapp",
  "networkMode": "awsvpc",
  "containerDefinitions": [{
    "name": "myapp",
    "image": "myorg/myapp:1.0",
    "portMappings": [{ "containerPort": 8080 }],
    "memory": 512,
    "cpu": 256
  }],
  "requiresCompatibilities": ["FARGATE"]
}

Lambda — Serverless

Chạy code theo event, tự scale, trả tiền theo thời gian thực thi (ms). Giới hạn: timeout 15 phút, memory tối đa 10GB. (Event-driven, auto-scaling, pay per execution. Limits: 15-min timeout, 10GB max memory.)

# Lambda handler (Node.js)
exports.handler = async (event) => {
  const userId = event.pathParameters.id;
  // ... business logic ...
  return { statusCode: 200, body: JSON.stringify({ ok: true, userId }) };
};
3. Storage & Database

S3 — Object Storage

Lưu file không giới hạn, độ bền 99.999999999% (11 nines). Bucket + object + versioning + lifecycle policy + static website hosting. (Unlimited object storage, 11-nines durability. Buckets, versioning, lifecycle policies, static hosting.)

# Lưu log/artifact từ pipeline
aws s3 cp app.jar s3://my-artifacts/releases/app-1.0.jar
aws s3 sync dist/ s3://my-static-site/

RDS vs DynamoDB

🗄️ RDS (SQL)

PostgreSQL, MySQL, SQL Server... Quan hệ, transaction, joins. Managed: auto backup, patching, multi-AZ, read replicas.

⚡ DynamoDB (NoSQL)

Key-value/document. Single-digit-ms latency, scale ngang không giới hạn. Phù hợp: session, cart, high-traffic.

Khi nào chọn gì?

  • Cần join/transaction phức tạp → RDS
  • Read-heavy, cần scale lớn, access pattern đơn giản → DynamoDB
  • File, media, backup → S3
  • Cache, session → ElastiCache (Redis)
4. Networking & Security

VPC — Mạng ảo riêng

Mỗi tài khoản có VPC mặc định. Chia subnet: public (có Internet Gateway) và private (không truy cập internet trực tiếp — qua NAT Gateway). (Default VPC per account. Subnets: public with IGW, private without direct internet — via NAT Gateway.)

# Cấu trúc VPC chuẩn (multi-AZ)
VPC 10.0.0.0/16
├── Public subnet  (10.0.1.0/24) — ALB, Bastion
├── Private subnet (10.0.2.0/24) — EC2 app
├── Private subnet (10.0.3.0/24) — RDS (không internet)
└── NAT Gateway + Internet Gateway

Security Groups vs NACL

🛡️ Security Group

Stateful firewall cấp instance — chỉ allow rules. Dòng trả lời tự động được phép. Gắn vào EC2/ALB/RDS.

📋 NACL

Stateless firewall cấp subnet — có allow + deny. Cần khai báo cả chiều vào/ra. Lớp phòng thủ thứ 2.

IAM — Quản lý quyền

Mọi thao tác AWS đi qua IAM: Users (người), Roles (quyền tạm cho service/EC2/Lambda), Policies (JSON quy định quyền). (All AWS operations go through IAM: users, roles, policies.)

# Policy tối thiểu cho EC2 đọc S3
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": ["s3:GetObject", "s3:ListBucket"],
    "Resource": ["arn:aws:s3:::my-bucket", "arn:aws:s3:::my-bucket/*"]
  }]
}
5. AWS cho DevOps

Bộ công cụ CI/CD của AWS

CodeCommit (repo) → CodeBuild (build) → CodePipeline (orchestrate) → CodeDeploy (deploy EC2/Lambda/ECS)

CodePipeline

Orchestrate toàn bộ release — trigger từ push, chạy qua build/test/deploy.

CodeBuild

Managed build service — compile, test, tạo artifact. Trả theo phút build.

CodeDeploy

Deploy app lên EC2/ECS/Lambda — hỗ trợ rolling, blue/green.

IaC trên AWS

CloudFormation

IaC native AWS (YAML/JSON) — deploy stack gồm nhiều resources. Có CloudFormation Designer, StackSets.

Terraform + AWS

IaC đa nền tảng — dùng provider AWS. Ưu tiên nếu team multi-cloud hoặc muốn chuẩn chung.

Monitoring AWS

  • CloudWatch — metrics, logs, alarms, dashboards.
  • X-Ray — distributed tracing cho Lambda/ECS/API Gateway.
  • CloudTrail — audit log mọi API call (bảo mật/compliance).
6. Câu hỏi phỏng vấn (Interview Questions)

❓ EC2 vs Lambda?

EC2: VM có kiểm soát, chạy liên tục, trả theo giây — workload dài. Lambda: serverless theo event, tự scale, trả theo ms — workload ngắn, không quản lý server.

❓ RDS vs DynamoDB?

RDS = SQL quan hệ, transaction, join. DynamoDB = NoSQL key-value, latency thấp, scale ngang lớn.

❓ S3 dùng làm gì trong DevOps?

Lưu artifact build, backup, static website, Terraform remote state, log. Độ bền 11 nines, rẻ.

❓ IAM Role vs User?

User gắn credentials cố định cho người. Role cấp quyền tạm thời cho service (EC2, Lambda) — an toàn hơn, tự rotate.

❓ VPC private subnet truy cập internet?

Qua NAT Gateway (NAT chỉ cho đi ra, không cho vào) — app trong private vẫn cập nhật package được mà không lộ port.

❓ CloudFormation vs Terraform?

CloudFormation: native AWS, đơn giản cho stack AWS. Terraform: multi-cloud, state management, modules — chuẩn hóa hơn cho team lớn.
